# Myshkin451

I work around agents, knowledge systems, and personal publishing.

I am interested in software as a way of thinking in public: tools that keep
context alive, interfaces that change how people read and write, and systems
that make memory useful in everyday work.

## Current Interests

| Area | Notes |
| --- | --- |
| Agentic systems | Long-running agents, tool use, memory, evaluation, and human-in-the-loop workflows. |
| Context infrastructure | RAG, code understanding, knowledge graphs, provenance, and better ways to bring context into work. |
| Personal knowledge OS | Notes, archives, reading traces, private workflows, and personal software. |
| Publishing as interface | Websites, digital gardens, and writing systems that can grow with ongoing work. |
| AI-native development | Coding environments where humans, agents, tests, and documentation work together more closely. |

## Notes

I prefer quiet work over performance: read first, change narrowly, explain
tradeoffs, and leave traces that make future understanding easier.
